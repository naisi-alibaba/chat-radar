# chat-radar · 3 分钟上手

## ① 先白嫖看效果（不用装）

双击项目里的 `demo/index.html`，浏览器会打开一个演示控制台——这就是你装完后每天看到的样子（里面的群名和内容都是**编的示例**）。觉得有用，再往下装。

## ② 装（Windows 最省事）

1. **装运行环境**：去 <https://nodejs.org> 下 LTS 版，一路「下一步」。
2. **下工具**：本仓库右上 `Code → Download ZIP`，解压。
3. **双击 `install.cmd`**：会自动开浏览器安装向导，跟着点——装飞书 CLI、扫码授权你自己的飞书、装依赖，一步步来。
4. **配 AI key**：去 <https://platform.deepseek.com> 注册 → 充 ¥10（能用很久）→ 建一个 API Key → 填进向导的输入框。

> Mac / 爱用命令行的：见 README 的命令行安装，几条 `npm` 命令的事。

## ③ 第一次用

- 双击 `console.cmd`，浏览器打开你的控制台。
- 点右上「⚙ 配置」填一次**信息版图**：你负责啥、关注啥、关键人是谁、关键词。填了 AI 才知道「什么对你重要」。
- 回首页点「↻ 立即看一遍」，等它把你的群扫一遍（第一次稍久，之后只盯有新消息的群）。
- 卡片出来：🔥 火线先看，🎯 该你拍板的别拖，💬 接话的搭一句，🔇 免看的放心装死。

## ④ 以后每天

早上双击 `console.cmd` 扫一眼。想让它自己盯，打开「自动盯梢」选个间隔；不想费 token 就关掉、手动点刷新。

## 常见问题

- **要花钱吗？** 工具本身免费开源。只有 DeepSeek 的 AI 调用按量计费，充 ¥10 能用很久——因为它只对「有新消息」的群才动用 AI。
- **会泄露我公司群吗？** 不会。只读你本人能看到的群、数据全程在你自己电脑、没有作者的服务器、AI 用你自己的 key。
- **装卡住了？** 群里 @我，把报错截图发出来，手把手带。

## 想截图发小红书 / 朋友圈？

用 `demo/index.html` 截（数据是编的，安全）。**千万别直接截你自己的真实控制台**——那里全是你公司的真群名、真人名。
